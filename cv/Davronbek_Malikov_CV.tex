\section*{Projects}

\textbf{Soccer Player Salary Predictor} --- Industry-level ML Pipeline \hfill \href{https://github.com/davronbek-malikov/soccer-xG-salary_prediction}{[GitHub]} $\cdot$ {\large\textbf{\href{https://soccer-xg-salary-prediction.onrender.com}{Live}}}
\begin{itemize}
    \item Built an end-to-end supervised ML pipeline predicting professional soccer players' annual
gross salaries from season-level performance statistics across Bundesliga, La Liga, and
Serie A (8 seasons, 2014/15--2021/22).
    \item \textbf{Data leakage prevention:} Train/test split before any fitting; StandardScaler and OrdinalEncoder fitted on training data only; target salary never imputed at any stage.
    \item \textbf{Modeling tiers:} Baseline (Linear Regression, Ridge, Lasso, Decision Tree) $\rightarrow$ Improved
(Random Forest, XGBoost, LightGBM, Gradient Boosting) $\rightarrow$ Ensemble (Stacking with
Ridge meta-learner, Voting regressor).
    \item \textbf{Feature engineering:} 21 derived features without using the target --- per-game rates
(xG/game, assists/game), efficiency index $(goals+assists)/(xG+xA)$, contribution index,
shot conversion, position simplification.
    \item \textbf{Hyperparameter tuning:} Optuna Bayesian optimisation (TPE sampler, 60 trials) over
n\_estimators, max\_depth, learning\_rate, subsample, and L1/L2 regularisation.
    \item \textbf{Explainability:} SHAP TreeExplainer --- global beeswarm and bar charts, local waterfall
and force plots, engineered-feature impact report confirming FE added signal.
    \item \textbf{Deployment:} Gradio demo live on Render, kept active 24/7 via UptimeRobot (5-min
ping). Full end-to-end daily logging throughout the pipeline.
    \item Linked to SCIE publication (Applied Sciences, 2025) --- 17\% improvement in prediction
accuracy. \href{https://doi.org/10.3390/app15148108}{[DOI]}
    \item Stack: Python, XGBoost, LightGBM, Scikit-learn, SHAP, Optuna, Gradio, Render, UptimeRobot.
\end{itemize}

\textbf{TacticalDNA} --- Unsupervised Player-Archetype Discovery \hfill \href{https://github.com/davronbek-malikov/tactical-dna}{[GitHub]} $\cdot$ {\large\textbf{\href{https://soccer-player-clustering.onrender.com}{Live}}}
\begin{itemize}
    \item Companion project to the Salary Predictor: same Big-5-league dataset (Bundesliga, La Liga,
Serie A), this time solving an unsupervised problem with zero salary/target leakage.
    \item Built an end-to-end clustering pipeline over 6,314 qualified player-seasons ($\geq$900 minutes)
using only per-90 performance features --- no salary, age, or team involved in the grouping.
    \item \textbf{Validated finding:} a blind stat line (25 goals, 15 assists, no name attached) was matched
by the model to prime Messi's 2019/20 season at 98\% cosine similarity --- pure identity recovery
from raw performance shape, with no player identity ever fed to the model.
    \item \textbf{Algorithm bake-off:} KMeans, Agglomerative (Ward), DBSCAN, and Gaussian Mixture
compared on Silhouette, Davies-Bouldin, and Calinski-Harabasz scores; KMeans won outright.
    \item \textbf{Documented negative result:} DBSCAN collapses to a single dense cluster across every
eps/min\_samples tested --- reported as a genuine empirical finding, not hidden.
    \item \textbf{Model selection trade-off:} chose $k=6$ over the statistically optimal $k=3$ for product
interpretability --- a deliberate statistical-optimum-vs-usefulness decision.
    \item \textbf{Archetype naming:} rule-based labeling from cluster centroids --- Elite Complete Forward,
Clinical Poacher, Deep-Lying Playmaker, Efficient Impact Player, Volume Forward, Defensive Anchor.
    \item \textbf{Deployment:} interactive Streamlit demo on Render; PCA(2) projection chosen over
t-SNE/UMAP for stable, real-time inference on new player input.
    \item Stack: Python, Scikit-learn, Streamlit, Plotly, Render.
\end{itemize}
